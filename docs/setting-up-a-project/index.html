Setting up a project

For whoever creates the project, usually the crew lead. The crew do not repeat it: they join the project you publish.

Create it

Open More → Projects and tap the + button at the bottom right. Only Name is required, but set the area before you save.

  • The area (PROJECT EXTENT ): Set extent on map to drag a rectangle over the study area, or Use current location for about a kilometer around where you stand. It is where maps open, and it is the area the offline maps below and the checklist’s map line cover, so make it the whole study area.
  • The time zone (TIME ZONE ): The days tags go on and come off are days in this time zone, wherever the phone showing them is. It is worked out from the center of the area (Chosen from the center of your project area. ). If that is wrong, tap Change time zone and search for a city. Changing it later rewrites nothing: days already recorded stay the same days.

Then tap SAVE PROJECT . It becomes the open project. To change any of this later, use Edit project in the project’s row menu.

Finish setting up

A new project is followed by one sheet with two choices, both ticked.

  • Publish to the server now : shown only when the phone is signed in. It makes you the project’s owner on the server, which is what lets the crew join.
  • Download offline maps for this area now : the map and elevation for the project’s area, with an estimate of the size. Do it on wifi.

Start does both. Keep TriTrack open until the download finishes: it pauses if you leave the app. Later starts nothing, and Later leaves these on the Pre-Trip Checklist.

More offline maps

Each phone keeps its own maps, so every member of the crew downloads them too. For more than the project’s area, or a different shape, draw it yourself: More → Manage Offline Maps → Manage on map , then New selection . The steps are on the map page.

The Pre-Trip Checklist

More → Pre-Trip Checklist checks what the phone needs before it loses cell or wifi coverage. Two lines are about this setup:

  • Offline maps for this project's area : done only when the map and the elevation both cover the whole area. Otherwise it gives the size and a Download button.
  • Published to the server : shown only when a server is set up.

Publish before the crew can join

A project that is only on your phone cannot be joined. Publish it from the sheet above, or later with Publish to server in the project’s row menu under Projects . Then open Members , turn on Let people join with a code , and give the crew the code. The rest is on joining a project.
