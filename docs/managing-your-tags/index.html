Your tags, and a project's tags

A tag is one transmitter: its frequency, pulse modes and name. Which animal wears it, and since when, is a separate dated record called a deployment, and a bearing’s animal comes from that record.

More has two lists with similar names:

  • Tag Library : every tag on this phone, on a project or not.
  • Tags : the tags on the project you have open.

Your Tag Library

Tags are grouped under a heading for each project that uses them, plus Not on any project ; tap a heading to open it. Type in Search by frequency or name to find one (part of a frequency works). The + button adds a tag, and tapping a tag opens it to edit.

To put a library tag on a project, hold the handle at the left of its row and drag it onto the project’s heading, then tap Add . The dialog says The project gets its own copy of the tag. The project it came from keeps its copy. You can also reorder the project headings by their handle on the right.

The library belongs to this phone, so no project role limits it, and nothing in it is sent to a server unless you push an edit to your projects (below).

Bulk import CSV reads tags in from a spreadsheet, and Export tags CSV writes the library out. Check the file for tags you already have before importing: These become new tags in your library. A row for a tag you already have makes a second, separate tag.

A project’s tags

More → Tags lists the open project’s tags. A tag that is not active (recovered, lost, a suspected malfunction) shows that on its row.

Copy from library adds a copy of a library tag to the project, the same as dragging it in from the Tag Library.

Who may do what. Any contributor can copy a tag in. Changing, removing or restoring a tag the project already has is for owners, because it changes what the team’s earlier bearings were taken against. A contributor sees You can copy tags into this project. Only a project owner can change one the project already has, or remove or restore it. A viewer sees Viewers cannot change a project's tags — ask an owner to change your role. Anyone can still open a tag and read it; one you may not change opens under Only an owner can change this tag .

Putting a tag on an animal

Open More → Animals , the animal, then Link a tag . Pick from On this project , from From your Tag Library (copied into the project in the same step), or New tag… .

The date is when the tag went on, and it decides which animal each bearing on that tag belongs to. It starts as today; tap Change if the tag went on earlier. If moving the date changes the animal some bearings belong to, the app counts them and asks before saving.

Many animals at once. Quick add on the Animals screen takes the date, species and pulse rates once under Same for all , then one row per animal: name and frequency. Type rows, paste them from a spreadsheet, or import a CSV. Review shows what each row will do (use a tag the project has, copy one from the Tag Library, or make a new tag named by its frequency), and nothing is saved until you confirm there.

In the field, ＋ Add new tag on the Record screen’s wheel makes a tag, an animal and today’s deployment in one go. Use it only for a tag that is not in your library yet, or you will have two records of one transmitter.

A copy is a copy

Editing the library does not change any project’s copy, and editing a project’s copy changes only that project. Each copy keeps its own history, so two projects can describe one transmitter differently. A library tag that projects use says so on its form, for example Changes here won't reach the 1 project using this tag , and a project’s copy shows Copied in on with its date. The (i) beside either line explains the copy.

Pushing a fix to every copy. After you save an edit to a library tag that projects use, the app asks Apply this to your projects? Accept, answer once whether the edit corrects a mistake or records a real change, and every copy is updated. Each copy keeps its own history. Projects where you are not an owner are counted, not skipped silently: could not be changed — you are not an owner there. Decline, and nothing outside the library changes.
