Joining a project

Joining needs a connection, both to ask and for the answer to come back, so do it before you lose signal. Everything after that works offline.

Sign in

Open More → Server Connection and enter the server address you were given. Tap REQUEST A SIGN-IN CODE with your email, then paste the code, or the whole link, into Sign-in code .

How the code reaches you depends on the server, and the app cannot know. If nothing arrives, ask whoever runs the server how codes are delivered.

If the server says it will not send to your address, check for a typo. If the address is right, this server only sends to plain unaccented letters, digits and ordinary punctuation; use another address or ask whoever runs the server.

Each phone signs in separately, with the same email.

Signing out. SIGN OUT on the same screen signs this phone out; it stops syncing and keeps everything it holds. If a phone is lost, use SIGN OUT EVERYWHERE from any of your devices: every device you are signed in on stops syncing, including the one you are holding. A lost phone keeps the data it already downloaded; that cannot be removed remotely.

If you own the project: hand out the code

Open Members (on the More tab, or in the project’s row menu under Projects ). The project must be published first, with Publish to server in that row menu.

Turn on Let people join with a code and give your crew the code any way you like. It does not expire and works for everyone.

  • New code replaces it, for example when somebody leaves the crew. Members stay; anyone still waiting has to ask again with the new code.
  • Team size limit caps the team. People waiting count toward it.

If you are joining: ask with the code

Open More → Projects → Join a project (above the list, even when it is empty). Type the Join code , check Your name , and tap Ask to join .

The owner sees your sign-in email, which the server vouches for, and the name you typed, labeled as what you said about yourself.

Asking is not joining

The screen says Waiting for approval , and the request stays under Your requests here and on the projects list, so you can leave.

Approving someone

Each request is under Waiting to join on Members , with the address, name and date.

Approve opens a sheet:

  • The role, starting at Contributor — records their own ; the others are Viewer — read only and Owner — also manages members . See roles.
  • The removal sentence, which you must tick: removing someone later stops their syncing but cannot delete what is already on their phone. Only let in people you trust with the locations they will carry away.

Reject declines; they are told and can ask again.

When the answer comes back

The project downloads by itself.

The phone checks every 60 seconds while the app is open, and at once when you bring it back to the front. A closed app checks nothing (there are no push notifications), so open it. Pull down on the projects list to check now.

When it does not work

  • Turned down: the card says so. Ask again with the same code.
  • The code changed while you waited: the card says so; ask for the new one.
  • Approved but nothing downloaded: the card says whether it has partly arrived or not started. It finishes the next time the app is open with a connection; nothing needs re-asking.
  • Nothing happening: open the app, find signal, pull down on the list. Most likely the owner has not looked yet.
