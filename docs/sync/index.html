Sync

Everything is recorded on the phone first. Sync sends it to the server and brings your teammates’ records back, whenever there is a connection; nothing in the field waits for it.

No server is fine

Without a server the app is complete: projects, tags, bearings, estimates, the map and exports. There is no sync mark and nothing reaches for the network. The rest of this page applies once a device has a project server and is signed in.

Where to look

  • The round icon above the + on the map. Tap it to open Sync Status .
  • A dot of the same color on the More tab, and on the Sync Status row inside it.
  • Sync Status itself, which says in words what happened and what to do.

The color and shape mean:

  • Green tick: up to date.
  • Amber triangle: something is behind or refused, but nothing is at risk.
  • Red exclamation: something is on this phone only, or nothing is getting through until somebody acts.
  • Gray: not a verdict. Offline (crossed-out cloud), syncing (spinning arrow), no longer on the project (a door out), or project deleted (exclamation in a circle).
  • No mark at all: no server is set up.

The shapes are there because about one man in twelve cannot tell the amber from the red. Records waiting to sync are normal after time out of signal; the count going down is a sync working.

Sync now, and when it syncs by itself

Sync now syncs at once, whatever the setting: tap it at the trailhead before the drive home.

The setting decides how long after the last sync the app tries again when it is open. It does not sync in the background: while the app is closed, nothing syncs at any of these settings.

  • Every time I open it : most current, most battery and data.
  • Every 15 minutes : the default; leave it.
  • Hourly : fewer round trips.
  • Only when I ask : nothing syncs until you tap Sync now , and the screen says that is why records are waiting.

Automatic sync uses cellular data too; there is no wifi-only setting. On a metered or satellite plan, choose Only when I ask .

When something goes wrong

The mark changes and Sync Status says what happened. In every case below, the records on your phone stay on your phone.

Offline

Gray, Offline , with the last successful sync. Not a fault: keep recording, and the next sync takes it all.

Some records not synced

Red: the server refused some records. They are kept, and the screen says These records are safe on this device, and only here until they sync — keep it backed up. Each card says why and what to do.

Under Waiting to sync , each record has a card with Why it is waiting , What you can do , when it was last tried, and Try again . Follow the card; it names the part of the record the server objected to when the server said, and says plainly when it did not. The usual fix is to retype pasted text, because pasted text can carry hidden characters the server will not store . Save, then tap Try again . The commonest case is a character in your own name; see below.

Some records did not arrive

Amber: a teammate on a newer version sent something this app cannot read (the server sent could not be read by this app. ). Nothing is lost. Update the app, and each record arrives the next time it changes.

You’re not on this project

Gray: You're no longer on this project, so it has stopped syncing. You left or an owner removed you. Everything on the phone stays and works offline. See projects, members and roles.

Project deleted

Gray, Project deleted : an owner deleted it from the server. This project was deleted from the server by a project owner, so nothing from this device will reach it again. Your records stay. Keep them with Export records on the project’s row under Projects , or Data Export / Backup , then delete the project from the phone. A phone that was offline at the time finds out on its next sync, however long it was away.

Offline too long to sync

Red, Offline too long to sync : a phone that has not synced a project for over two years is refused, because syncing could bring back records deleted meanwhile. Nothing on the phone changes; export a copy. There is no step in this app that fixes this — tell whoever runs your project server. Rejoining does not help. Before a long gap, ask about this.

Server doesn’t offer this

Red, Server doesn't offer this : the server answered, but not to this request. It is either older than the app, or a proxy in front of it answered instead; the app cannot tell which. Whoever runs the server should check both. Nothing on the phone is changed.

The server’s records were replaced

Not an error. A sentence starting with a date says the server was restored from a backup or rebuilt, so the phone is syncing the project over from the beginning: it fetches everything and sends back what the server lacks. Nothing on the phone was deleted. Expect a long fetch and a jump in records waiting.

Other states

  • Amber, access refused: an owner removed you, or this phone is signed in to an account that was never on the project (a shared phone). The app cannot tell which. If you expected to be on it, ask an owner; if it is not yours, open one of your own projects.
  • Amber, Signed out : tap it and sign in again. Records keep collecting meanwhile.
  • Red, Sync isn't working : repeated failures with no specific cause. If it persists, ask whoever runs your project server.

What a name may contain

Your first and last name go on every record and to your teammates’ phones. A name may contain only:

  • letters and their accents, in any writing system (Đặng Thị, Fernández)
  • digits (Bill Gates 3rd)
  • hyphens and dashes, spaces (including the wide Japanese space), apostrophes straight or curly (O'Brien)
  • full stops and commas (J. R. Smith, Smith, Jr.), and the middle dot (ジョン・スミス)

Anything else is refused, including at-signs, brackets, slashes and emoji, so Dana Reyes (PhD) will not save. Those characters can make a name pass for an email address on someone else’s screen.

The setup screen and your profile check as you type. A character you can see is quoted back to you: delete it. An invisible one (usually from a paste) is named by its code point, with Delete the whole field and type it again .

A name refused after it was saved is held at sync, not lost; correct it on your profile and it goes. A teammate whose name is refused is missing from your phone until they fix it; their bearings are unaffected.

Back up what has not synced

Unsynced records exist only on that phone. Before a week out of signal, take a backup file off it: see getting your data out.

There are no notifications. The mark on the More tab is the only signal, and you see it when you open the app.
