Quick start

Six steps, in order. The first time you open TriTrack it asks for your name and email, which label everything you record.

1. Create the project

Open More , then Projects , and tap the + button at the bottom right. Give it a Name and tap SAVE PROJECT ; it becomes the open project. More in projects, members and roles.

2. Add the animals and their tags

On More → Animals , tap Quick add . Set the day the tags went on once, at the top, then type one row per animal: its name and its frequency, or paste the rows from a spreadsheet. A frequency that matches no tag on the project or in your Tag Library becomes a new tag. Nothing is saved until you tap Review and then the add button under it. More in putting a tag on an animal.

3. Download offline maps

On wifi, download your study area from More → Manage Offline Maps , and keep the app open until it finishes. Each phone keeps its own maps, so every member of the crew does this. More in downloading map tiles.

4. Run the pre-trip checklist

More → Pre-Trip Checklist . Before you lose signal, every line should show a tick rather than an exclamation mark: your identity, map tiles, elevation data, the project’s tags, a GPS fix and the compass. The line under each says what it found. More in how it works.

5. Invite the crew

This step needs a project server and a connection. Sign in under More → Server Connection , then choose Publish to server from the three-dot button on your project’s row under Projects , then Members from the same menu. Turn on Let people join with a code and give the code to your crew. Each of them signs in the same way, asks with the code under Projects → Join a project , and you approve each one. More in joining a project.

6. Take the first bearing

On the Record tab, spin the wheel to the tag you are hearing. Point the antenna, tap POINT when the signal peaks (or hold RANGE while you sweep across it), say how good it was, and tap SAVE OBSERVATION . None of this needs a signal. More in recording a bearing.

With two or more bearings on one animal, the Position tab estimates where it is. See estimating a position.
