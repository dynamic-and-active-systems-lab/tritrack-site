Getting your data out

A spreadsheet is for analysis; a backup file moves a whole project or keeps a second copy of it. Both are under More → Data Export / Backup , and any role, viewers included, can use both.

Spreadsheets

Optionally filter by one tag or a date range, then tap Export CSV and choose where to save. You get one zip file named for the project and the date, holding:

  • observations.csv: one row per bearing, with time, position, magnetic and true bearing, uncertainty, quality, observer and notes;
  • non_detections.csv and truth_points.csv, when the project has any no-signal records or truth points;
  • tags.csv, individuals.csv and deployments.csv: the tags, the animals, and which tag was on which animal when.

The message afterwards counts what it wrote (observations, non-detections, truth points, tags, animals); a kind not mentioned had nothing in it.

Tag columns come in pairs: what the tag was called and tuned to when the bearing was taken, and what it is now, so a mid-season retune stays visible. A bearing too old to know what it was recorded against leaves the first pair empty rather than filling in today’s values, and a column says so.

A backup of the whole project

Export project backup (.zip) writes everything in the project (records, tags, people, map extent) into one small file you can send or store anywhere.

Import backup reads one back in. It adds to and corrects the project rather than replacing it; anything it would overwrite is listed, old value and new, before you agree. You need write access to the project.

Sending one record

To someone using TriTrack: on the Log tab, a row’s ⋮ menu has Share observation… , which copies a block of text. They open More → Observation Sharing , Paste from clipboard , Parse , and see it before anything is saved.

The card names who took the record (not who forwarded it) and whether the tag details are as recorded at the time or as they read on the sender’s phone today, which matters if the tag was retuned.

To someone who is not: tap a bearing, estimate or truth point on the map and use the share menu on its card. Copy coordinates copies the position, Open in Maps hands it to the phone’s maps app, and Share… sends a .gpx waypoint that a handheld GPS, Gaia or CalTopo can read. A bearing’s card also has Copy for TriTrack .

None of this is sync: it goes only to the person you send it to.

Back up what has not synced

Unsynced records exist only on that phone. When working out of signal for days, take a backup file off it every few days and put it somewhere else; it takes seconds. Sync Status shows how many records are waiting (sync).

On a Mac

The same screen and buttons, with the ordinary macOS save dialog, which is handy when the file is going straight into an analysis. There are no desktop pictures in this guide yet.
